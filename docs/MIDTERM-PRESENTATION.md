# Midterm Presentation Rules

Each team delivers a **15-minute** midterm presentation. Questions and answers occur after the
15-minute presentation time. Submit the slides and current team repository state before class.

Not every member must present the technical content. However, include one required team-membership
slide that lists every member's role and a concise description of that member's contribution during
Weeks 1–7. Each listed member briefly presents their own entry on this slide.

No slide template or point-by-point rubric is prescribed. The presentation should communicate the
team's current detection and recognition work, error analysis, and readiness for the alignment
stage.
