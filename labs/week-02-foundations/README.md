# Week 2 — Foundations: Lab Tutorial

[← Back to course README](../../README.md) · Previous: [Week 1](../week-01-orientation/) · Next: [Week 3](../week-03-detection-1/)

**Session:** each group reviews Week 1 (5 min/group), then this lab.

## Goals

- Become familiar with the NomNaOCR data in the team's assigned folder.
- Get the DP/edit-distance and weak-supervision concepts that Weeks 9–13 rely on.
- Write the project charter.

## Starter kit (given)

Full dataset access for the team's assigned folder; a blank project-charter template.

## Reading

Dang et al., "NomNaOCR: The First Dataset for OCR on Han-Nom Script," RIVF (2022).

## Tutorial steps

1. Receive the team's document folder/volume (from the paper's Table 4 list).
2. Browse images and line labels; note page quality, layout, and label conventions.
3. Skim a Needleman–Wunsch / edit-distance primer and one weak-supervision reference.
4. Fill in the charter template (goals, roles, risks).

## Tasks

- [ ] Browse the full images/line-labels for the team's assigned folder
- [ ] Skim a Needleman–Wunsch/edit-distance primer and one weak-supervision reference
- [ ] Team assigned one document folder/volume (from the paper's Table 4 list)
- [ ] Submit a one-page project charter (goals, roles, risks)

## Deliverable

Project charter; team assigned a document subset.
